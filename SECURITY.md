# Security Policy

## Supported Versions

Currently, the following versions of **Chymistry** are actively supported with security updates.

| Version                   | Supported          |
| ------------------------- | ------------------ |
| Latest Release / Active   | :white_check_mark: |
| Old / Legacy Builds       | :x:                |

## Reporting a Vulnerability

We take the security of our codebase and our users' servers very seriously. If you discover a critical security vulnerability (e.g., severe server-crashing exploits, arbitrary code execution, or economy-breaking duplication methods), please do **not** open a public issue.

Instead, please report it securely through the following method:

1. **GitHub Security Advisories**: Navigate to the [Security tab](https://github.com/yigit-guven/Chymistry/security/advisories) on this repository and click **"Report a vulnerability"**. This allows us to discuss and patch the issue in a private environment.

### What to Include

When reporting a vulnerability, please provide:
- The exact version of Chymistry and your Modloader.
- A clear description of the vulnerability and its potential impact on servers or clients.
- Detailed, step-by-step instructions to reproduce the exploit.
- Any relevant logs, crash reports, or proof-of-concept demonstrations.

### Response Timeline

We will acknowledge receipt of your vulnerability report within 48 hours. We will then investigate the issue and communicate a timeline for a patch. We kindly request that you maintain confidentiality and avoid disclosing the exploit publicly until a patch has been released and server administrators have had a reasonable timeframe to update.
