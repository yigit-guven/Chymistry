# Creosote Oil

**Item ID:** `chymistry:creosote_oil`

**Creosote Oil** is a combustible, preservative-grade coal tar distillate.

## Acquisition

Distilled in an **[Alembic](Alembic)** with an adjacent Glass Bottle:

| Station | Inputs | Time | Output |
| :--- | :--- | :---: | :--- |
| **[Alembic](Alembic)** | 1x Coal + 1x Any Wood Log | 15s (300t) | **1x Creosote Oil** (In Glass Bottle) |

---

## Uses

1. **[Wood Treatment](Wood-Treatment)**:
   * Combine 1x Creosote Oil with 8 matching wooden blocks in a crafting table to create fireproof **Treated Wood**. Returns the empty bottle.
2. **High-Efficiency Furnace Fuel**:
   * Burn duration of **2,400 ticks** (smelts **12 items**, outperforming standard coal by 50%). Returns an empty Glass Bottle.
3. **[Storm Ritual](Storm-Ritual)**:
   * Combined with **[Storm Powder](Storm-Powder)** inside a **[Crucible](Crucible)** to summon atmospheric precipitation.
