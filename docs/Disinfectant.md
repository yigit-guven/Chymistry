# Disinfectant

**Item ID:** `chymistry:disinfectant`

**Disinfectant** is a medical antiseptic solution formulated from alcohol, mineral quicklime, and purified sea salt.

## Mechanics

### 1. Poison Antidote (Ingestion)
* **Drinking**: Consuming Disinfectant immediately cures the **Poison** status effect and returns an empty Glass Bottle.

### 2. Zombie Villager Cure
* **Entity Interaction**: Right-clicking a **Zombie Villager** with Disinfectant immediately initiates its transformation into a regular Villager.
* Bypasses the need for a Splash Potion of Weakness or Golden Apple.
* Consumes 1x Disinfectant and returns an empty Glass Bottle.
