# Cyan Dye Composter

The **Cyan Dye Composter** is a biochemical solvation block created during [Production Composting](Production-Composting).

## Mechanics

1. **Creation**: Formed when a player interacts with a **Level 7 vanilla Composter** using either **[Alcohol Bottle](Alcohol-Bottle)** or **Raw Copper**.
2. **Reaction**:
   * Insert the remaining reactant so that both **1x Alcohol Bottle** and **1x Raw Copper** are dissolved within the composter.
   * Inserting the Alcohol Bottle returns an empty [Reinforced Glass Bottle](Reinforced-Glass-Bottle).
   * Celebratory green villager particles trigger when the reaction reaches completion.
3. **Harvesting**:
   * Right-click the composter with an empty hand to collect **2x Cyan Dye**.
   * The block resets to an empty vanilla Composter.
