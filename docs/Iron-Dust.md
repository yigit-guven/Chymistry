# Iron Dust

**Item ID:** `chymistry:iron_dust`

Iron Dust is an item registered by the mod. 

## Acquisition
Iron Dust is obtained by processing Raw Iron in [The Mortar](Mortar).

![Iron Dust Recipe](images/recipe_iron_dust.png)

* **Recipe:** 1x `minecraft:raw_iron`
* **Click Speed:** Any
* **Presses Required:** 3
* **Yield:** 1x Iron Dust
