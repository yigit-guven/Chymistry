# Alcohol Bottle

**Item ID:** `chymistry:alcohol_bottle`

**Alcohol Bottle** is a concentrated bio-ethanol distillate contained in an acid-resistant [Reinforced Glass Bottle](Reinforced-Glass-Bottle).

Distilled in an **[Alembic](Alembic)** with an adjacent Reinforced Glass Bottle:

| Station | Inputs | Time | Output |

## Uses

* **[Disinfectant](Disinfectant)**: Distilled in an **[Alembic](Alembic)** alongside Quicklime and Sea Salt.
* **[Cyan Dye Composting](Cyan-Dye-Composter)**: Added to a Level 7 Composter alongside Raw Copper to produce 2x Cyan Dye. Returns the Reinforced Glass Bottle.
