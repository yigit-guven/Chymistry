# Copper Dust

**Item ID:** `chymistry:copper_dust`

Copper Dust is an item registered by the mod. 

## Acquisition
Copper Dust is obtained by processing Raw Copper in [The Mortar](Mortar).

![Copper Dust Recipe](images/recipe_copper_dust.png)

* **Recipe:** 1x `minecraft:raw_copper`
* **Click Speed:** Any
* **Presses Required:** 2
* **Yield:** 1x Copper Dust
