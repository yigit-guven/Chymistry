# Freezing Powder

**Item ID:** `chymistry:freezing_powder`

**Freezing Powder** is an endothermic chemical powder capable of triggering instant phase-change crystallization.

## Usage

* **[Freezing Conversion](Freezing-Conversion)**:
  * Right-click any **Water Source** block to instantly freeze it into **Blue Ice**.
  * Right-click any **Lava Source** block to instantly solidify it into **Obsidian**.

---

## Synthesis

Synthesized in a cryogenic **[Crucible](Crucible)** resting above Ice or Blue Ice:

| Station | Inputs | Temperature Range | Time | Output |
| :--- | :--- | :---: | :---: | :--- |
| **[Crucible](Crucible)** | 4x Snowballs + 1x [Niter Dust](Niter-Dust) | -64 to 0 Heat | 10s (200t) | **2x Freezing Powder** |
| **[Crucible](Crucible)** | 1x Snow Block + 1x [Niter Dust](Niter-Dust) | -64 to 0 Heat | 10s (200t) | **2x Freezing Powder** |
