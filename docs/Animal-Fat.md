# Animal Fat

**Item ID:** `chymistry:animal_fat`

Animal Fat is a rendered organic lipid used as a foundational reagent in biochemical and cleansing recipes.

## Acquisition

Animal Fat is acquired by processing animal meats or monster flesh in a **[Mortar & Pestle](Mortar)**:

| Input | Output | Presses | Speed |
| :--- | :--- | :---: | :---: |
| 1x Raw Porkchop | 1x Animal Fat | 3 | Any |
| 1x Raw Beef | 1x Animal Fat | 3 | Any |
| 1x Raw Mutton | 1x Animal Fat | 3 | Any |
| 2x Rotten Flesh | 1x Animal Fat | 4 | Any |

## Uses

* **[Soap](Soap)**: Combined in a heated **[Crucible](Crucible)** with Quicklime and a Water Bucket to formulate Soap bars.
