# Vigor Potion

**Item ID:** `chymistry:vigor_potion`

**Vigor Potion** is a restorative herbal tonic contained in a [Tinted Glass Bottle](Tinted-Glass-Bottle).

## Effects

* **Consumption**: Drinking grants the **[Vigor](Vigor)** status effect for **10 seconds** (0:10).
* **Restoration**: Rapidly regenerates the player's health pool proportionally to their maximum health.
* Returns an empty [Tinted Glass Bottle](Tinted-Glass-Bottle) when consumed.

---

Distilled in an **[Alembic](Alembic)** with an adjacent Tinted Glass Bottle:
