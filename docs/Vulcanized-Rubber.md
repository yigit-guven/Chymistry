# Vulcanized Rubber

**Item ID:** `chymistry:vulcanized_rubber`

**Vulcanized Rubber** is a chemically stabilized thermoset elastomer cross-linked with sulfur compounds.

## Overview

* Produced by treating raw polyisoprene with sulfurous agents and thermal curing.
* Provides acid-resistant, non-conductive, and shock-dampening qualities.
