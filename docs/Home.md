# Chymistry Wiki

> **Last Updated:** September 5, 2026 &bull; *Version 1.1.0*

**Chymistry** is a comprehensive early-chemistry and alchemical modification for Minecraft. It bridges traditional alchemical themes with methodical, multi-step scientific processing, introducing custom interactive workstations, thermal dynamics, distillation, chemical synthesis, and hazardous materials.

Welcome to the official documentation. Select a category below or use the sidebar to explore workstations, mechanics, materials, and reagents.
