# Vitriol Immunity

**Effect ID:** `chymistry:vitriol_immunity`

Vitriol Immunity is a custom status effect (Mob Effect) registered by the mod.

## Source
This effect is currently only obtainable by consuming the [Elixir of Vitriol](Elixir-of-Vitriol).

## Mechanics
While active, Vitriol Immunity provides complete protection against **Poison** and **Wither** effects:
*   Prevents new Poison and Wither effects from being applied.
*   Immediately cures any existing Poison and Wither effects upon application.
