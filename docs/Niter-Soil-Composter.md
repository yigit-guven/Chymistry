# Niter Soil Composter

The **Niter Soil Composter** is an intermediate agricultural transformation block created during [Production Composting](Production-Composting).

  <img src="images/blocks/compostmodel.png" width="48" style="image-rendering: pixelated;">
</div>

## Mechanics

1. **Creation**: Formed when a player interacts with a **Level 7 vanilla Composter** using **[Ash](Ash)**.
2. **Extraction Options**:
   * **[Niter Dust](Niter-Dust)**: Right-click the composter with an empty hand to harvest 1x Niter Dust and return an empty composter.
   * **[Super Fertilizer](Super-Fertilizer)**: Insert **[Niter Dust](Niter-Dust)** and **Bone Meal** into the composter (alongside the original Ash). When all three components are present, right-click with an empty hand to retrieve 1x Super Fertilizer.
