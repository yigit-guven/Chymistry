# Repellent Base

**Repellent Base** is a pungent alchemical totem block that suppresses hostile mob spawning when thermally vaporized.

## Mechanics

Repellent Base has **600 points of durability** (lasting 10 continuous minutes).

### Vaporization in Crucible
1. Place a Repellent Base inside any **[Crucible](Crucible)**.
2. Heat the crucible to **≥ 20 Heat** using a thermal source below.
3. The base begins to smolder, venting crimson spores and fragrant incense.
4. **Spawn Suppression Field**:
   * Completely disables natural monster spawning in a **32-block spherical radius** (1024 sq. blocks).
   * Consumes 1 durability per second (20 ticks).
   * When durability depletes, the base burns away cleanly.
