# Rust Powder

**Item ID:** `chymistry:rust_powder`

**Rust Powder** is pulverized iron oxide obtained through the aqueous oxidation of refined iron.

## Acquisition

Submerge an **Iron Ingot** into a water-filled **[Cauldron](Cauldron)**:

| Station | Input | Water Cost | Time | Output |
| :--- | :--- | :---: | :---: | :--- |
| **[Cauldron](Cauldron)** | 1x Iron Ingot | 1 Level | 10s (200t) | **1x Rust Powder** |

---

## Uses

* **[Incendiary Dust](Incendiary-Dust)**: Pulverized in a **[Mortar](Mortar)** alongside Gunpowder to formulate volatile pyrotechnic dust.
