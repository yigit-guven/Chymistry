# Immunity

**Effect ID:** `chymistry:immunity`

**Immunity** is a protective status effect that grants absolute protection against all other status effects.

## Mechanics

* **Complete Shielding**: Every tick, any other active status effect on the entity is instantly purged and canceled.
* The entity cannot be poisoned, withered, slowed, blinded, weakened, or burdened by any negative condition.
* **Source**: Conferred by drinking the **[Potion of Immunity](Potion-of-Immunity)** (duration: 3 minutes).
